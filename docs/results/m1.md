## Demo (`make demo`)

`ticker-server -seed 1 -step 50ms` on 127.0.0.1:50551, then `tickerctl` (log:
[`docs/proof/demo.jpg`](../proof/demo.jpg)):

- `quote ACME`: one quote.
- `stream -symbols ACME,FLUX -interval-ms 100 -n 6`: 6 quotes, ticks 28, 30, 32 (the 50 ms market
  moves twice per 100 ms round; the stream samples the latest price), then the server ended the
  stream.
- `watch -add ACME,BLUE`, then `CRNA` added and `ACME` dropped: two acknowledgements
  (`[ACME BLUE]`, `[BLUE CRNA]`), quotes only for the watched set, clean end after the client closed
  its side.
- `quote NOPE`: `NotFound`. `stream -n 0` with a 300 ms client deadline: 3 quotes, then
  `DeadlineExceeded`.
- After the script, no `ticker-server` process was left running.

## Analyze

- The first govulncheck run failed: grpc-go v1.84.0 pulled `golang.org/x/net` v0.57.0, which has
  four advisories reachable from this code (GO-2026-6617, GO-2026-6612, GO-2026-6611,
  GO-2026-6603, all fixed in v0.60.0). Root cause: the indirect dependency was older than the
  fixed release. Fix: require `golang.org/x/net` v0.60.0 (with `x/sys` v0.48.0 and `x/text`
  v0.42.0). The rerun reported "No vulnerabilities found."

## Improve and Control

- CI runs gofmt, go vet, buf lint and format, the generated-code drift check, the breaking-change

  annotations with their RESULT lines.
- The server enforces message size, stream count, symbol count, interval and update limits, and
